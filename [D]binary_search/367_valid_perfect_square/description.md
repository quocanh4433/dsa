## Problem Description:

Given a positive integer num, return true if num is a perfect square; otherwise, return false.

A perfect square is an integer that is the square of another integer.

In other words, there exists an integer x such that:

x * x = num

```java
Input: num = 16
Output: true
Explanation: 4 * 4 = 16
```


```java
Input: num = 14
Output: false
Explanation: There is no integer whose square is 14.
```

Constraint:

```java
1 <= num <= 2^31 - 1
```
